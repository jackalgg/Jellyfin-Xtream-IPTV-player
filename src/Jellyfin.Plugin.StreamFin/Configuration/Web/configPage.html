StreamFin IPTV

Connect an Xtream Codes panel or an M3U playlist. Live channels land in Live TV with their guide attached, and films and shows become ordinary Jellyfin libraries with seasons, episodes, resume, and Next Up.

Advanced

Each show needs its own request for the episode list. Raise this to sync faster, lower it if the panel starts refusing connections.
Plots and cast need one request per film, so each sync enriches this many new titles and remembers them. A large catalogue fills in over several runs.
Other Jellyfin IPTV plugins hand the panel URL to ffmpeg, which then fails because the panel wanted a browser User-Agent or a different file extension. StreamFin plays the title itself, the way TiviMate or VLC would, then hands the bytes to Jellyfin. Turn this off only if you want the raw panel URL in the generated files.
Most panels bounce a channel to a nearby server. Resolving that first is usually the difference between a channel that starts instantly and one that times out.
